# Wallpaper-Studio
Wallpaper Studioは、手持ちの画像や動画をWindowsのデスクトップに表示し、自動で切り替える壁紙アプリです。  
自分が欲しい機能を備えたPC向け壁紙アプリが見つからなかったため、自作しました。画像・動画のランダム表示と、縦型・横型が混在するマルチモニター環境での使いやすさにこだわっています。少しずつアップデートしていく予定です。  
以下は **Wallpaper Studio 3.3.1** を基準にした機能紹介です。  

### マルチモニター

- 複数のモニターへ、それぞれ異なる画像・動画を表示できます。
- 壁紙を切り替える対象モニターを個別に選べます。
- モニターごとに、登録した全ソースから選ぶか、指定したソースから選ぶかを設定できます。
- 1台のモニターに複数のソースを割り当てられます。
- 特定のモニターだけ画像・動画を固定表示できます。
- モニター構成を再検出できます。接続状態の変化も動作中に検出します。
- モニター別の壁紙機能が利用できない環境では、画面全体に合成した壁紙を使う互換表示に対応しています。
- モニターと向きが異なる静止画像を、90度回転して表示する設定もあります。オフ、時計回り、反時計回り、ランダムから選べ、初期値はオフです。正方形画像や動画には適用しません。

### 表示・切り替え

- 「今すぐ切替」と、設定した間隔での自動切替を選べます。
- 切替間隔はプリセットから選ぶほか、数値を入力して指定できます。
- 静止画像同士の切替にクロスフェードを付けられます。
- フェード時間はプリセットのほか、0.2～30秒の範囲で指定できます。
- 切替アニメーションを使わない軽量な表示も選べます。
- 静止画像の余白を、画像の端を拡大・ぼかして補うか、画面の形に引き延ばすかを選べます。
- 静止画像にグレースケール、セピア、柔らかい色、鮮やか、暖色、寒色、落ち着いた暗さの効果を適用できます。効果を毎回ランダムに選ぶ設定もあります。
- フルスクリーンアプリが前面にあるときは、フェード用の画面を出さずに壁紙を更新します。
- 動画が関わるモニターは即時切替し、ほかのモニターの静止画像同士にはフェードを使えます。

### 動画の壁紙

- MP4、M4V、MOV、WMV、AVI形式の動画を無音で壁紙として再生できます。
- 動画を設定した切替間隔で次へ進めるか、再生終了まで待つかを選べます。
- 縦型モニターに横長動画を表示する場合などは、映像を中央に収め、余白を黒く表示します。
- 動画から静止画像へ戻る際は、次の壁紙を準備してから動画表示を外します。
- 動画同士の切替では、次の動画の最初のフレームが表示されるまで前の動画を保持します。
- 再生できなかった動画のエラーをログに記録します。

### 操作・管理

- 登録したソースの順序を入れ替えられます。
- 指定したアプリの起動中は自動切替を保留し、そのアプリの終了後に再開できます。
- アプリ起動時に自動切替を開始する設定があります。
- Windowsへのログイン時に常駐起動する設定があります。
- ウィンドウを閉じても通知領域で動作させられます。
- Windows標準壁紙へすぐ切り替えられます。
- 静止画像向けに「低解像度画像の拡大方法」をメニューバーから設定できます。従来の「バイキュービック」、「バイキュービック＋弱い鮮鋭化」、「ランチョス補間」の3つを選べます。
- 自動切替の開始・停止、次の壁紙、表示履歴などをショートカットキーで操作できます。キーの割り当ても変更できます。
- 最近表示した画像・動画を、日時、モニター、種類、縦横分類、保存場所、解像度とともに確認できます。
- 表示履歴から画像や動画のプレビュー、検索、ファイルを開く、保存場所を開く、パスのコピー、Google レンズで検索ができます。
- 選択中のソースや全ソースに含まれる画像・動画の数、画像の縦横分類を確認できます。
- 読み込めない画像と、その理由を確認できます。
- 画像・動画一覧の再スキャン、現在の壁紙の再描画ができます。
- 設定と表示履歴を保存し、旧版からの設定引き継ぎに対応しています。

## 対応形式

- **画像:** JPEG（`.jpg` / `.jpeg` / `.jpe` / `.jfif`）、PNG、BMP / DIB、GIF、TIFF
- **追加条件付きの画像:** WebPは実行ファイルと同じフォルダに `libwebp-7.dll` が必要です。JPEG XR（`.jxr` / `.wdp`）、HEIC / HEIF、AVIFは、Windows側に対応する画像コーデックがある場合に利用できます。
- **アニメーション** GIF。確認が不十分なので順次アップデートで不具合を修正していきます。
- **動画:** MP4、M4V、MOV、WMV、AVI。実際に再生できるかどうかはWindowsのメディアコーデックに依存します。H.264映像のMP4を推奨します。

## 使い方

1. 配布ファイルを展開し、実行ファイルを起動します。WebPを使う場合は `libwebp-7.dll` を実行ファイルと同じフォルダに置いてください。
2. 「フォルダ追加」または「画像・動画追加」で表示したいファイルを登録します。
3. 対象モニターを選び、必要に応じて「このモニターの詳細設定…」からソースや固定ファイルを指定します。
4. 選び方、切替間隔、余白の処理、切替アニメーションなどを設定します。
5. 「今すぐ切替」または「自動切替を開始」を押します。

アプリ内の「ヘルプ」→「使い方」（`F1`）からも基本操作を確認できます。

## 利用上の注意

- 本アプリはWindows向けです。
- 動画は無音で再生します。形式が対応一覧にあっても、Windowsのコーデックやファイルの内容によって再生できない場合があります。
- 動画の表示速度は、元動画のフレームレート、PCの負荷、同時に再生するモニターの数によって変わります。
- フェードは静止画像同士の切替で使用します。初回の切替、動画が関わる切替、フルスクリーンアプリの使用中などは通常の切替になります。
- 旧版から更新する場合は、通知領域で動作中の旧版を「完全に終了」してから新版を起動してください。従来の設定と履歴は引き継ぎます。
- 表示に使う画像・動画の権利は、各利用者が確認してください。配布物に第三者の画像・動画を同梱する場合も同様です。
- WebP用の `libwebp-7.dll` を同梱する場合は、配布物に `LICENSE-libwebp.txt` も含めてください。
