# Wallpaper-Studio v3.3.1
自分が欲しい機能が搭載されたPCの壁紙アプリがなかったので自作しました。少しずつアップデートしていく予定です。  
・指定したファイル内にある画像/動画のランダムスライドショー機能  
・画像切り替え時のフェード機能  
・モニターの縦長/横長を認識してそれに合う画像をピックアップする機能
